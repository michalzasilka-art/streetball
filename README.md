# Streetball (Foxino Olympics)

A fugio.co game: https://www.fugio.co/streetball/ (all the Olympics games: https://www.fugio.co/olympics/)

This repo is a copy of the game exactly as it is published on fugio.co. It is a static web game (HTML + JavaScript,
no build step): the files are served from the site's `streetball/` folder and use the Foxino Olympics code in `olympics/common/` (the `olympics/` folder is also the Olympics page, https://www.fugio.co/olympics/).

Every publish of the game is one commit with a version tag: v001, v002, v003, ...
